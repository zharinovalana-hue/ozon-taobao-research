# Ozon × Taobao: сценарная продуктовая модель

Обновлённая существующая модель кейса «Корзина — не копилка». Сравнивает H1–H6 по изменению глобальной дневной конверсии Ozon в уникального пользователя с заказом и отдельно проверяет CR Корзины, CR Избранного и условный ARPU.

**Это сценарная модель, не прогноз результатов A/B-теста.** Все гипотезы получают одинаковые +10% относительной CR целевой группы до штрафов. Численные охваты и риски, не подтверждённые данными, явно остаются допущениями. Taobao измеряет уникальные добавления за окно, Ozon-кейс — остатки SKU. Перенос формы когорт является внешним стрессом.

В Excel выбран сценарий №6 «Taobao / Ozon: базовый». На листе **Параметры**, ячейка **B3**, можно выбрать другой сценарий. **Итоги** пересчитываются формулами. Первые три сценария и исходные C:E входы сохранены; №2 точно воспроизводит прежний базовый результат.

**Сравнение** содержит сохранённые результаты всех сценариев. Изменение селектора не делает их устаревшими. При изменении численных входов появляется предупреждение: для обновления таблицы запустите Python. Жёлтые поля на листах **Сценарии** и **Входы H** позволяют проводить локальные эксперименты в Excel; для сохранения таких решений в воспроизводимом процессе перенесите их в JSON/код сценариев.

## Пересчёт без большого датасета и без Codex

Требуется Python 3.11+; CI использует Python 3.12. Скачайте/клонируйте весь репозиторий, включая файлы `models/`.

```bash
python -m pip install -r requirements.txt
python scripts/run.py
python -m unittest discover -s tests -v
```

Команда читает небольшие JSON-агрегаты из `data/`, заново рассчитывает все CSV/JSON в `results/` и обновляет **существующий** Excel. Исходный XLSX и полный архив не нужны для обычного пересчёта. Рабочая модель служит шаблоном: её листы, стили, диаграмма и формулы сохраняются. Расчёт поддерживаемого набора формул обновляет сохранённые значения, включая данные диаграммы. При неизвестной функции или циклической ссылке пересчёт завершается явной ошибкой.

Чтобы получить отдельную копию:

```bash
python scripts/run.py --output Ozon_recalculated.xlsx
```

Правила и коэффициенты: `data/model_inputs.json`; сценарии: `src/ozon_model.py::scenarios`. `data/scenarios.json` — автоматически полученный результат, его ручная правка будет перезаписана. Масштаб 44/84 млн соответствует марту 2026, а не измеренной аудитории учебных когорт.

## Обновление Taobao

Если уже есть `taobao_users.csv`, повторно обрабатывать архив не требуется:

```bash
python scripts/run.py --users /path/to/taobao_users.csv
```

CSV содержит ровно `user_id,cart_count,fav_count,purchased`. Должна быть одна строка на пользователя; нули и False сохраняются. Пользовательский CSV не коммитится. В GitHub попадают только маленькие сводки, пороги и контрольная сумма.

Для полного прогона откройте [блокнот](notebooks/taobao_reproducible.ipynb) в Colab. По умолчанию он использует существующий файл `/content/drive/MyDrive/taobao_users.csv`. Только при `REBUILD=True` или отсутствии агрегата он читает `/content/drive/MyDrive/UserBehavior.csv (1).zip`. Архив повторно загружать не нужно. Из Colab переносите в `data/` только две сводки, затем запускайте обычный пересчёт.

Прямой запуск Colab из текущей интеграции не доступен; при подготовке публикации использован ранее рассчитанный агрегат из Drive. Его итоги перепроверены, исходный гигабайтный архив заново не обрабатывался.

## Проверки и ограничения

Сохранённые исходные 45 проверок выполнены на импортированном и обновлённом Excel через Artifact Tool; все 26 сценариев сверены с независимым Python-расчётом. Публичный Python-тест проверяет все исходные сохранённые формулы, отсутствие расхождений кешей и полную воспроизводимость без Drive. Настроен [GitHub Actions](.github/workflows/verify.yml).

Артефактная проверка не равна запуску настольного Excel. Пересчёт формул и данные диаграммы проверены программно; визуально проверены изменённые представления. Фактическая причинная эффективность, платформа/устройство, пересечения целевых задач, абсолютная дневная CR и доход на покупателя Ozon остаются неизвестными. H6.1/H6.2/H6.3 имеют одинаковые условные входы, поэтому равны в расчёте; складывать их нельзя.

Данные учебного кейса синтетические. Реальные публичные показатели Ozon и внешние исследования используются только в методологически совместимых ролях; источник и ограничения каждого переноса перечислены в документации.
