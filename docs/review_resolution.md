# Независимое ревью и исправления

Ревью выполнено отдельным агентом в режиме чтения до публикации. Критических замечаний не найдено. Подтверждённые замечания закреплены регрессионными проверками:

1. Изменение общего uplift не помечало сохранённые сравнения устаревшими. B10 включён в контроль входов; изменение 0,1→0,2 теперь вызывает предупреждение.
2. Python принимал разные веса для четырёх когорт, Excel использовал только первую строку. Добавлена полная матрица весов по сценарию и когорте в правой части «Входы H»; перенос JSON→Excel проверен на изменении веса S3.
3. Часть масштаба была повторно записана константами. DAU/MAU, число дней, заказы и масштабированные охваты теперь выводятся из единого public_ozon и фактов кейса; обновление конфигурации проверено.
4. Добавлены проверки конечности uplift и границ вероятности покупателей, чтобы неверный вход не давал отрицательные покупки.
5. Для нецелого интерполированного процентиля выбран порог ceil: условие «count≥P90» не включает значения ниже процентиля. Для текущего агрегата все четыре пороговые пары целые, результаты не изменились.

Ревью не устанавливает истинность допущений и не заменяет проверку в настольном Excel или полный прогон исходного архива. Эти ограничения сохранены в README и выводах.
